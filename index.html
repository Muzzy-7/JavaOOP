Anomaly #1 • Empty Catch Block Swallowed Exception

Catching broad Exception with an empty body hides the root cause and tricks callers into thinking the transfer succeeded.

Anomaly #2 • Leaked AutoCloseable Unclosed VaultLock

Because syncRemote() threw before lock.close(), the lock stayed open without a finally or try-with-resources block.

Anomaly #3 • Non-Atomic State Orphaned Debit

src.debit(amt) mutated state before IOException aborted dst.credit(amt), leaving the ledger unbalanced.
